# Code of Conduct

Opal is a friendly, welcoming project. Everyone who participates — in issues, pull requests, discussions or any other
project space — is expected to:

- be respectful and considerate, and assume good intent
- give and accept constructive feedback gracefully
- focus on what is best for the project and its users
- welcome newcomers and help them get started

Unacceptable behaviour includes harassment, insults or personal attacks, discriminatory language or imagery,
publishing others' private information, and any conduct that would be inappropriate in a professional setting.

## Enforcement

Maintainers may remove comments, commits, code, issues and other contributions that do not follow this code of
conduct, and may temporarily or permanently ban contributors for behaviour they deem harmful.

Report problems privately to the maintainer through the contact details on the
[maintainer's GitHub profile](https://github.com/enprevo). All reports are handled confidentially.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
